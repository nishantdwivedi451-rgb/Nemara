# NEMARA — Wear Your Story.

A digital fashion house for **Nemara**, a new-age fashion jewellery brand from India founded by **Pratima Saxena**: fashion editorial, Indian artistry, contemporary jewellery, technology and human stories in one shoppable experience.

**Creative direction:** *The Annotated Edition*, a fashion magazine its designer has written in. See [`docs/CREATIVE_DIRECTIONS.md`](docs/CREATIVE_DIRECTIONS.md) for the three directions explored and why this one was chosen.

## What's inside

| Area | Highlights |
|---|---|
| **Brand system** | Original Didone wordmark + "N-with-a-bead" mark (`components/brand/Logo.tsx`), ink-purple palette, Instrument Serif / Instrument Sans / Caveat, arch motif, cinematic CSS motion |
| **Homepage** | Ink-drawn campaign hero (sketch → jewellery), manifesto, interactive *Nemara World*, *Choose Your Moment*, story teaser, new-arrivals rail, typographic index, founder, try-on, artists, stylist |
| **Shop** | Editorial grid (products interrupted by campaigns, artist stories, margin notes), filters, sort, search, category/moment/collection landing pages |
| **Product page** | 4-slot gallery (piece · worn · detail · sketch), buy box with artist credit, sizes, sticky mobile bag, **Idea → Hand → Making → Moment** story module, complete-the-look |
| **Artists & Our Story** | Artist ecosystem (product ↔ artist ↔ other pieces), seven-chapter founder story |
| **Try It On** | Camera try-on with on-device face/hand tracking (MediaPipe), manual & photo fallback, snapshot + share, provider abstraction (`TRY_ON_PROVIDER`) |
| **Nemara Stylist** | Occasion/outfit/budget-aware styling engine behind a chat UI, AI-ready interface |
| **Commerce** | Cart drawer, wishlist, guest checkout with PIN autofill, server-side repricing, Razorpay (UPI/cards/net banking/wallets), Shopify adapter, demo mode |
| **Nemara Studio** (`/admin`) | Private OMS + inventory + catalogue manager + Circle membership capture + birthday/festival/abandoned-cart automation, synced live with the storefront |
| **Platform** | SEO (metadata, OG, canonical, sitemap, robots, Product/Breadcrumb/Org/Article JSON-LD), modular analytics, CSP & security headers, a11y, rate-limited validated APIs |

## Quick start

```bash
npm install
npm run dev            # http://localhost:3000
npm run build && npm start
npm run typecheck
npm run art            # regenerate placeholder illustrations
```

Node ≥ 20.9. No environment variables are required to run: the site starts with the local catalogue and demo checkout.

## Replacing placeholder imagery

All imagery in `public/art/` is original, licence-free placeholder illustration generated by `scripts/generate-art.mjs`. To use real photography, drop files into `public/media/` (or a CDN / Shopify) and change the `src` strings in `content/*.json`. No component changes are needed.
